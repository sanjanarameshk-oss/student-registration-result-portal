# 🎓 Student Registration & Result Portal

A responsive mini project developed using HTML5 and CSS3.  
This project allows students to enter their personal details, select a course, enter examination marks, and view their results.

## 🚀 Live Demo

🔗 http://127.0.0.1:5500/index.html

Click the link above to view the project live in your browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## ✨ Features

- Student registration form
- Personal details entry
- Course selection
- Examination marks entry
- HTML5 form validation
- Student result display
- Responsive design
- Styled tables, cards and buttons

## 📁 Project Structure

Student-Registration-Result-Portal/
│
├── index.html
└── style.css

## 🎯 Objective

The objective of this project is to understand how HTML5 and CSS3 can be used together to create an interactive and responsive Student Registration & Result Portal.
